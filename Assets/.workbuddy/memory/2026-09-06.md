### 架构要点（与 TDD 一致）
- `SokobanRules` 是移动逻辑唯一实现，GameMode 与 ForwardBfsSolver 都调它（硬性规则达成）
- 坐标 **y 向上**（TDD 里 Up=(0,-1) 的屏幕写法未采用，Delta Up=(0,1)）
- LevelData.cells 用**扁平 int[]**（JsonUtility 不支持锯齿数组），语义仍 cells[y][x]
- 快照在 Step 执行**前**抓取（执行后抓会存到新状态 —— 写时踩过，已修）
- BackwardBfsSolver 暂为占位：先用正向短超时兜底，出结论就用；否则如实 Timeout（P1 可砍方案落地）

### 踩坑记录（重要）
1. **asmdef 无法引用 Assembly-CSharp** —— 测试 asmdef 引用不到游戏代码。解法：Scripts 加 `Sokoban.Runtime.asmdef`、Editor 加 `Sokoban.Editor.asmdef`，测试引用 Sokoban.Runtime
2. **asmdef defineConstraints UNITY_INCLUDE_TESTS 会让程序集平时不编译**，测试收集 0 个的坑 —— 去掉该约束
3. **AllBoxesOnGoal() 空箱子数组 vacuous true** —— 无箱关卡天然"已通关"，Step 全锁死（NoOp）。修复：Boxes.Length==0 → false。这个 bug 是三层排查（测试失败→execute_code 复现→逐层调用定位）抓出来的
4. FNV-1a 64 offset basis 超出 long.MaxValue，需 `unchecked((long)...UL)` 转换
5. MCP 的 refresh 不总能触发编译，可靠手段：`AssetDatabase.Refresh(ForceUpdate)` + 检查 Library/ScriptAssemblies DLL 时间戳

## 追加：16:9 文字模糊二次修复（2026-09-06 晚，用户 23:21 反馈"仍模糊"）

上一轮 Expand 只解决了"不裁切"，但 16:9 下竖版页（设计 720x1280）被 Expand 放大 **2.67 倍** → legacy Text 经 GPU 双线性放大 → 文字发虚（9:16 仅 1.5 倍所以用户觉得正常）。

### 修法（根因 = 放大倍率过大）
- **竖版页（主菜单/选关/编辑器）改用 `Shrink`（按高度适配，16:9 下缩放=0.844 ≤1 → 缩小→文字锐利）+ 居中留边**。但 Shrink 会把画布逻辑尺寸拉成 2275x1280，使边锚点元素被撑散 → 故在 `UIRouter.WrapPortraitPages()` 把竖版页内容整批包进固定 720x1280 的居中「Content」容器（运行期，不动 prefab），内容 anchoredPosition 原样保留，视觉不变。
- **横版页（HUD/结算/暂停，设计 1280x720）仍用 `Expand`**：16:9 下正好 1.5 倍（与方向布局预设配合，且 16:9 即其本比例，1.5 倍可接受）；改 Shrink 会破坏其竖屏 405x720 方向布局。
- 场景 `Game.unity`：3 个竖版页 Canvas `ScreenMatchMode` 由 `Expand(1)` 改 `Shrink(0)`（让"不进 Play"编辑器预览也用 Shrink，锐利且不裁切）；3 个横版页保持 `Expand(1)`。
- `GameEditorShell.EnsurePlayButton`：运行时「试玩」按钮改挂到「Content」容器内，避免竖版页包裹后错位。
- 确认链路：纯 Screen Space - Overlay + legacy `UnityEngine.UI.Text` + 无相机/无后处理 → 锐利度只取决于缩放倍率。

### 验证
- 编辑器开着项目，自动重编译通过（Editor.log 无 error CS / Compiler Error）。
- 待用户 Play 实测：16:9 主菜单/选关/编辑器文字是否锐利；HUD 在 16:9 为 1.5 倍（轻微，若要求像素级可把 HUD 设计改 1920x1080 并重算 LandscapePose）。

### 修正上一轮教训
- "Shrink 必裁切"只适用于**内容直接铺在画布上**的情形。若把竖版页内容包进固定尺寸居中容器，Shrink 表现为「按高度收缩 + 居中留边（pillarbox）」，全可见、不裁切、且缩放≤1 故文字锐利。这才是竖版 UI 在横屏的正确解法。
