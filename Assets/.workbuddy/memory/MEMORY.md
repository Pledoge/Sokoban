## 硬性规则（不能破）

- **玩家与敌人永不重合，且是双向的**：玩家不能走进敌人格，敌人不能走进玩家格，任一方该步整体取消。
- 求解器**必须复用运行时同一个 `Step()`**，绝不另写转移逻辑 —— 否则规则漂移，会把有解关卡误判为无解。
- 拓展模式 BFS 必须保留「玩家撞墙」的转移边（v2 后这是合法的、会改变世界的操作）。
- UI 的 `onClick` **不直接挂 prefab**，写在独立脚本按名字查找绑定，否则重导入丢绑定。
- 反向 BFS 的死锁剪枝语义是正向的**转置**，必须单独单测防误杀。
- **坐标系硬一致（09-07 新增）**：关卡数据 `cells[y*width+x]` 的 y 轴，**游戏 `BoardRenderer` 用 y 向上（y=0 在底部）**。两个编辑器（`GameEditorShell` 运行时壳 / `LevelEditorWindow` IMGUI）的网格渲染**必须用 y 向上**，否则导出关卡在游玩时上下翻转。改编辑器渲染/输入映射时务必核对 y 方向，不要翻转数据本身。
