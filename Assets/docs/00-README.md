## 核心交付物 Checklist

**玩法**

- [ ] 经典模式：可玩、UI 完整、撤销、重置、关卡切换、胜负判定
- [ ] 拓展模式（含邪恶推箱人）：可玩、行为符合 [GDD §3.1](./01-游戏设计文档\(GDD\).md) 的四种组合
- [ ] 计步：只计玩家有效步，撤销不减步，拓展模式不计敌人步

**编辑器**

- [ ] 游戏内编辑器：画外墙、放物体、保存/加载、解判定
- [ ] Unity Editor 插件：菜单 `Window / 推箱子 / 关卡编辑器`，接 Unity Undo
- [ ] 双形态共用 `EditorCore`，同一操作序列产出 JSON 一致

**解判定**

- [ ] 正向 BFS（≤ 8 箱）+ 反向 BFS（9~15 箱）混合，按箱子数切换
- [ ] 死锁剪枝（dead square 预计算），拓展模式只走正向
- [ ] 超时如实告知，不假装有结果

**美术与 UI**

- [ ] 奶蛙风角色 + 场景素材（AI 生图 + 色块占位兜底）
- [ ] 7 套 UI 走 UI Builder 产出并导入 `Assets/UIBuilder/`
- [ ] 每套 UI 在 9:16 / 9:19.5 / 9:21 / 16:9 下检查无遮挡

**适配与交付**

- [ ] 棋盘任意比例下完整可见、不变形；HUD 贴边；移动端 SafeArea + 滑动输入
- [ ] 至少 3 个内置关卡（1 经典 + 1 拓展 + 1 教学/演示）
- [ ] 仓库可拉下即跑（README + 资源 + 代码齐全）
