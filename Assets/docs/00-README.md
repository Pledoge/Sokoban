## 项目定位

- **项目名**：推箱子黄金无敌至尊版（Sokoban GOE）
- **引擎**：Unity 2022.3 LTS（工程当前为 `2022.3.62f3c1`，与题目要求 `2022.3.51f1` 同一 LTS 系列，API 兼容）
- **目标一周内交付到 GitHub**，包含完整关卡体验 + 关卡编辑器
- **平台**：PC（主，键盘 / 手柄）+ 移动端（次，滑动手势）

| ------ | -------------- | -------------------------------------------------------------------------------- |

| **v4** | **2026-09-07** | **局内美术落地 + 关卡库（内置/自制/导入）+ 编辑器能力增强 + 求解器/渲染 bug 修复集**。见 ADR 16~21，详见下方「v4 变更摘要」 |

> - v2 连带影响：入栈判定改为「世界状态哈希变化」；玩家移动新增「撞敌人不动」；求解器必须保留玩家撞墙的转移边。
> - v3 连带影响：编辑器核心抽成 `EditorCore`（双形态共用）；求解器拆成正向 / 反向 + 路由；UI 不再逐张出图，改走工具链。
> - v4 连带影响：关卡增加 `source` 来源字段（选关分类依赖它）；`WorldState` 必须把 `BoxOnGoal` 还原为 `Goal` 地形；选关页每次进入都要重扫关卡目录。

### v4 变更摘要（2026-09-07）

| 类别 | 内容 |
|---|---|
| **美术** | 8 张奶蛙暖金风局内素材落地（`Assets/Resources/Art/`）：玩家奶蛙 / 邪恶推箱人 / 木箱 / 金色箱子 / 终点 / 砖墙 / 障碍岩石 / 地板砖；`BoardRenderer` 优先加载美术、缺失回退程序化色块；渲染分层（地板 0 / 地形 1 / 动态 2），箱子推上终点换金色皮肤 |
| **关卡库** | 导入 **Microban 155 关**（David W. Skinner，免费分发需署名）；`LevelData.source` 区分 `内置 / custom 自制 / imported 导入`；选关页支持 **分类标签 + 搜索 + 分页**；保存后立即重扫可玩 |
| **编辑器** | 按住拖动连续放置（每格每笔只变一次）；出生点/敌人全局唯一且放置后整盘刷新；关卡名称输入框；试玩/通关可「返回编辑器」 |
| **解判定** | 「校验」= 结构校验 **+ 真求解器**（3s 超时）：明确输出 有解(N 步) / 无解 / 超时；障碍按不可通行参与计算 |
| **修复** | `BoxOnGoal` 终点丢失导致带 `*` 关卡无解；`Deadlock` 竖直方向判界越界 + 贴墙段含终点被误标死格；missing script（`UIBuilderDoc` 拆独立文件）；编辑态预览随鼠标漂移；重置按钮不刷新棋盘 |

## 核心交付物 Checklist

**玩法**

- [x] 经典模式：可玩、UI 完整、撤销、重置、关卡切换、胜负判定
- [x] 拓展模式（含邪恶推箱人）：可玩、行为符合 [GDD §3.1](./01-游戏设计文档\(GDD\).md) 的四种组合
- [x] 计步：只计玩家有效步，撤销不减步，拓展模式不计敌人步

**编辑器**

- [x] 游戏内编辑器：画外墙、放物体（含拖动连刷）、保存/加载、解判定
- [x] Unity Editor 插件：菜单 `Window / 推箱子 / 关卡编辑器`，接 Unity Undo
- [x] 双形态共用 `EditorCore`，同一操作序列产出 JSON 一致
- [x] 关卡名称输入框 + 试玩 / 通关可返回编辑器 + 保存后立即出现在选关

**解判定**

- [x] 正向 BFS（≤ 8 箱）+ 反向 BFS（9~15 箱）混合，按箱子数切换
- [x] 死锁剪枝（dead square 预计算），拓展模式只走正向
- [x] 超时如实告知，不假装有结果
- [x] 障碍按不可通行参与计算；校验通过后再跑真求解器给出「有解 / 无解 / 超时」

**美术与 UI**

- [x] 奶蛙风局内素材 8 张（AI 生图落地 + 程序化色块兜底）
- [x] 6 套 UI 走 UI Builder 产出并导入 `Assets/UIBuilder/`（主菜单 / 选关 / HUD / 暂停 / 结算 / 编辑器）
- [x] 竖屏 1080×1920 与横屏 16:9 下检查无遮挡（编辑态预览与 Play 共用同一套缩放引擎）

**关卡库**

- [x] 内置 5 关（教学 1 + 经典 2 + 拓展 2）
- [x] 导入 Microban 155 关（标记 `source=imported`，署名 David W. Skinner）
- [x] 自制关卡（标记 `source=custom`，编辑器产出，与导入关卡分类展示）

**适配与交付**

- [x] 棋盘任意比例下完整可见、不变形；HUD 贴边；⚠️ 移动端 SafeArea + 滑动输入（未收尾）
- [x] 关卡数量 ≥ 3（实际 160+）
- [ ] 仓库可拉下即跑（README + 资源 + 代码齐全）—— 项目根 README 待补
