# 推箱子黄金无敌至尊版（Sokoban GOE）🐸✨

> **奶蛙推箱手 VS 邪恶推箱人** —— 一款带对手机制的 2D 推箱子游戏，
> 内置 **关卡编辑器** 与 **可解性求解器**，附带 160+ 关卡库。
>
> 技术策划笔试交付 · Unity 2022.3 LTS · 纯 C#，零第三方依赖

---

## ✨ 特色

- **双模式玩法**：经典 Sokoban + 独创「邪恶推箱人」镜像对手
- **160+ 关卡**：5 关内置 + Microban 155 关（经典名集，已署名导入）+ 玩家自制
- **游戏内关卡编辑器**：画墙放物、拖动连刷、一键校验「有解 / 无解 / 超时」、试玩闭环
- **AI 美术 + 程序化兜底**：奶蛙暖金风素材由 AI 生成，缺图自动回退色块，美术与逻辑解耦
- **UI Builder 工具链**：全部 UI 由自研网页排版工具产出（策划排版 → JSON → Unity 一键导入）
- **19/19 编辑器单元测试**：规则、求解器、编辑器核心全覆盖

## 🎮 快速开始

1. 用 **Unity Hub** 打开本工程（`2022.3.51f1+` LTS 均可，工程使用 `2022.3.62f3c1`）
2. 打开场景 `Assets/Scenes/Game.unity`
3. 点 **Play** —— 主菜单 → 选模式 → 开玩

### 操作

| 按键 | 功能 |
|---|---|
| `方向键` / `WASD` | 移动 / 推箱 |
| `Z` | 撤销（整个世界回退，包括敌人） |
| `Y` | 重做 |
| `R` | 重置本关 |
| `N` | 下一关 |
| `Esc` / `P` | 暂停 |

## 🕹️ 玩法

### 经典模式

标准 Sokoban：把所有箱子推到金色终点即过关。注意死锁——箱子贴墙推进角落就救不回来了。

### 拓展模式 · 邪恶推箱人

在经典规则上加入一个对手：**你每走一步，它就朝与你相反的方向执行一次同样的操作**（能移就移、能推就推）。

- 它不能走进你的格子，你也不能走进它的格子——任一方该步整体取消；
- **你撞墙不动 ≠ 它不动**：只要它的方向能走，它照走（这是本作的核心博弈点，用撞墙“垫步”能诱导对手）；
- 撤销会回退整个世界（你 + 对手 + 所有箱子），但**步数不会减少**（防刷步）。

### 选关

关卡选择页支持 **分类标签（内置 / 自制 / 导入）+ 搜索（关卡名 / ID / 作者）+ 分页**。
编辑器刚保存的关卡立刻出现在「自制」分类里，无需重启。

## 🛠️ 关卡编辑器

双形态共用同一套核心逻辑（`LevelEditorCore` 纯 C#），保证行为一致：

| 形态 | 入口 | 面向 |
|---|---|---|
| **游戏内编辑器** | 主菜单 →「关卡编辑器」 | 玩家 / 评审（打包后仍可用） |
| **Unity 插件** | 菜单 `Window / 推箱子 / 关卡编辑器` | 策划 / 程序（开发期批量做关） |

**使用流程（游戏内）**：

1. 选工具（墙 / 玩家 / 敌人 / 箱子 / 终点 / 障碍 / 橡皮），**按住左键拖动可连续放置**（每格每笔只变一次）；
2. 玩家与敌人全局唯一，放新位置旧位置自动清除；
3. 点 **校验**：先查结构（箱终配平、外墙闭合），再跑**真求解器**——
   输出 `有解（约 N 步）` / `无解` / `超时`（障碍按不可通行参与计算，与实际游玩完全一致）；
4. 顶部输入框填关卡名 → **保存**，关卡立刻出现在选关页「自制」分类；
5. 点 **试玩** 直接开一局：暂停页 / 结算页有 **「返回编辑器」**，改完再试。

## 📦 导入自己的关卡集

支持标准 **XSB 文本格式** 的关卡集（`#` 墙 `$` 箱 `*` 箱在终点 `.` 终点 `@` 玩家）：

```bash
python .workbuddy-img/xsb2json.py   # 按脚本内路径放置你的 .txt 后运行
```

转换器自动处理：文本行序 → y-up 坐标、墙外空地填墙、id 补零、箱/终配平校验。
已用此管线导入 [Microban](http://www.abelmartin.com/rj/sokobanJS/Skinner/David%20W.%20Skinner%20-%20Sokoban.htm)
（David W. Skinner，155 关，可自由分发·需署名）。
