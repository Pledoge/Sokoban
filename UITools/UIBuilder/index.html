⌨ 快捷键一览（参照 Figma / Unity / PS 习惯）
快捷键功能
Ctrl/⌘ + Z / Ctrl/⌘ + Y撤销 / 重做（支持 100 步）
Ctrl/⌘ + C / Ctrl/⌘ + V复制 / 粘贴（支持多选批量）
Ctrl/⌘ + Shift + V粘贴到原位置（不带偏移）
Ctrl/⌘ + D复制并粘贴（duplicate，Unity/Figma 同款）
Ctrl/⌘ + A全选所有节点
Ctrl/⌘ + 点击多选 / 切换选择（画布与层级均支持）
Ctrl/⌘ + G / Ctrl/⌘ + Shift + G组合 / 取消组合（生成 Panel Group）
Alt + ← ↑ → ↓对齐：左 / 顶 / 右 / 底（多选，同父级）
Alt + Shift + ← / ↑水平居中 / 垂直居中
Ctrl/⌘ + Alt + C / Ctrl/⌘ + Alt + V复制样式 / 粘贴样式（颜色·形状·文本·图片）
Ctrl/⌘ + Shift + L锁定 / 解锁（锁定后画布不可拖动）
Ctrl/⌘ + Shift + H隐藏 / 显示（导出时保留标记，Unity 侧 SetActive 对应）
Ctrl/⌘ + ] / Ctrl/⌘ + [上移一层 / 下移一层（图层顺序）
Delete / Backspace删除选中（多选批量）
方向键 / Shift + 方向键微调位置 1px / 10px（多选整体移动）
Alt + 拖拽节点快速复制（Figma / PS 同款）
Ctrl/⌘ + K打开 ✨ AI 排版（模态内 Ctrl + Enter 直接生成）
Ctrl/⌘ + F按名称查找节点
F聚焦选中节点（展开其在层级中的路径）
F2重命名节点
Ctrl/⌘ + S导出完整包（程序可直接导入 Unity）
Esc取消选中 / 关闭菜单
提示： 对齐 = 以所有选中节点（多选）的整体包围盒为基准彼此对齐（左/右/顶/底/居中），仅限同一父级；可点属性面板「已选 N 个节点」里的对齐按钮，或按 Alt+方向键。
属性面板的「高级选项」里可精确调整锚点；组合（Ctrl+G）不会改变节点在世界坐标中的位置。
